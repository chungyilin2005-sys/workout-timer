# 核心燃脂計時

居家運動用的倒數計時網頁。選擇 2、5、10、20 或 30 分鐘，系統會自動編排成「燃脂動作＋核心動作」交替的間歇課表，畫面上的插畫人物會示範每個動作。

網址：https://chungyilin2005-sys.github.io/workout-timer/

## 使用方式

1. 用手機打開網址，選一個時間。
2. 把手機放在地上或靠牆，距離 1～2 公尺。運動中螢幕會保持常亮。
3. 人物腳下的墊子會隨時間填滿：紅色是運動、綠色是休息、藍色是準備、暖身或收操。
4. 最後 3 秒會有嗶聲，換動作時有提示音。iPhone 請先關閉實體靜音開關。
5. 「結束」按鈕要在 3 秒內連按兩次才會結束，避免運動中誤觸。

建議把網址「加入主畫面」，用起來就像一個 App。

## 銀髮版

首頁上方可以切換「一般版／銀髮版」。銀髮版不跳躍、不趴地，只需要一張穩固、沒有輪子的椅子，提供 5、10、15、20 分鐘四種課表，每組運動 30 秒、休息 30 秒，而且一定有暖身和收操，字也比較大。

要傳給長輩時，直接給這個網址，打開就是銀髮版：
https://chungyilin2005-sys.github.io/workout-timer/?mode=senior

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 整個網站 |
| `AGENTS.md` | 給 AI（Claude Code 等）的維護說明 |
| `CLAUDE.md` | 讓 Claude Code 自動去讀 AGENTS.md |
| `.nojekyll` | 讓 GitHub Pages 直接發布，不另外處理 |

## 之後要修改時

在這個資料夾開啟 Claude Code，直接用中文說明想改什麼即可。Claude Code 會先讀 `CLAUDE.md`，再依指示讀 `AGENTS.md`，了解整個網站的架構與不能改壞的地方。

改完後在 GitHub 推送（push），約 1 分鐘後網站就會更新；若畫面沒變，電腦按 Ctrl＋F5，手機關掉分頁重開。
